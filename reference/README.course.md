# BOLA Lab

Учебная лаборатория Broken Object Level Authorization (BOLA / IDOR).

## Запуск

```bash
npm install
npm start
```

Откройте **http://localhost:3847/**

| Лаба | Содержание | Текст |
|------|------------|-------|
| [BOLA 1 — MediNotes](http://localhost:3847/bola) | Медицинский портал, IDOR | [DOCS/bola1.txt](../DOCS/bola1.txt) |
| [BOLA 2 — PayFlow](http://localhost:3847/bola2) | Финтех, 12 заданий | [DOCS/bola2.txt](../DOCS/bola2.txt) |
| [BOLA 3 — CloudVault](http://localhost:3847/bola3) | Multi-tenant, UUID, 15 заданий | [DOCS/bola3.txt](../DOCS/bola3.txt) |

Только localhost.
